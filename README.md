# 🌍 WanderAI - Advanced AI Travel Planning Platform

A commercial-grade, full-stack travel planning platform built with **Next.js (App Router)**, **OpenAI API**, and **Google Maps API**. 

Pick any destination and budget, then instantly generate a complete, personalized trip with top attractions, dining recommendations, and an organized day-by-day itinerary. Save your favorite trips, explore interactive maps with transit routes, re-mix days for rainy weather, settle group debts, communicate with native speech audio, check local scam radars, and export offline printable pocket booklets.

---

## ✨ Full Suite of Commercial-Grade Capabilities

### 1. 📅 Interactive Visual Travel Calendar & Google Sync
- **Interactive Departure Shift Engine**: Set your real departure date; the system automatically maps each itinerary day to actual dates with countdown timers.
- **3 Master Calendar Views**:
  - 🗓️ **Month Grid Matrix**: Visual monthly calendar with active trip dates highlighted, day indicators, and quick click-to-inspect.
  - ⏱️ **Timeline & Hourly Schedule (Gantt-Style)**: Morning (09:00 - 12:00), Afternoon (13:00 - 17:00), and Evening slots with category filters (Culture, Food, Nature, Nightlife).
  - 📋 **Master Chronological Agenda**: Printable / table agenda with all transit, budget estimates, and timing buffers.
- **1-Click Calendar Sync**:
  - Direct **Google Calendar** web intent links for every individual activity or full days (no download required, pre-filled with location & tips).
  - **Apple / Outlook / Android .ICS** universal download.
- **Smart Pacing & Activity Density Radar**: Pacing meters, estimated daily hours, and transit buffers.

### 2. 🧭 Luxury Two-Tier Navigation Dock & 27-Module Directory
- **Persistent Quick Jump Bar**: 1-click access to the top most critical traveler tools (Itinerary, Calendar, Map, Flight Radar, Group Splitter, Safety Shield).
- **Categorized Suites**: Cleanly separated into *Plan & Schedule (7)*, *Transit & Flights (5)*, *Budget & Finance (7)*, and *Smart Companion (8)*.
- **"All 27 Modules" Directory**: Searchable popover modal to quickly find and launch any travel system with keyboard search.

### 3. 👥 Avoid-the-Crowds & Foot-Traffic Heatmap Radar
- **Hourly Crowd Density Bars (06:00 to 23:00)**: Visual bar heatmaps for top attractions and museums.
- **Optimal Arrival Windows**: Pinpoints off-peak morning and evening hours to skip 90-minute tour bus queues.
- **Ticketing & Secret Gates Advice**: Timed slot booking reminders, secondary gate bypasses, and quiet nearby viewpoints.

### 4. 📮 AI Vintage Travel Postcards & Daily Memory Journal
- **Personalized Postal Canvas**: 4 themes (*Vintage Airmail 1974*, *Nordic Minimalist*, *Riviera Sun-Drenched*, *Cyberpunk Night*).
- **Authentic Postal Elements**: Real destination stamps with country flags, circular cancellation postmarks, and handwritten typography.
- **AI Travel Note Writer & Print Pass**: Generate poetic travel memories or write your own note, with 1-click print and share.
- **Daily Memory Journal**: Log daily emoji moods (*Euphoric*, *Adventurous*, *Food Coma*), best dishes, and personal reflections with browser auto-save.

### 5. 🪄 AI Itinerary Doctor & Day Re-Mixer (Live API)
- **Dynamic On-the-Fly Day Transformation**: Plans change on the road. Transform any specific day of your itinerary without regenerating the whole trip.
- **6 Intelligent Modes**:
  - ☔ **Rainy Day Rescue**: Automatically swaps outdoor parks and walking tours for covered arcades, museums, aquariums, and subterranean food halls.
  - 🍜 **Foodie Deep Dive**: Re-routes around iconic food markets, hidden alley street food, artisan roasteries, and Michelin Bib Gourmand dining.
  - 🧘 **Slow Travel & Wellness**: Later 10:30 AM starts, peaceful botanical strolls, thermal onsen/baths, and relaxed sunset wine.
  - ⚡ **High-Energy Adventure**: Urban bicycle routes, panoramic fortress climbs, and rooftop observation decks.
  - 🍸 **Night Owl & Speakeasies**: Afternoon craft cafes transitioning into hidden alley cocktail bars, live jazz, and night markets.
  - 🪄 **Custom Traveler Prompt**: Tell AI your exact hobbies, mobility requirements, or niche interests.
- **Live Preview & Confetti**: Side-by-side comparison ("Original" vs "AI Re-Mix") with 1-click apply and re-calculated transit paths.

### 2. 👥 Group Bill Splitter & "Who Owes Who" Debt Settler
- **Travel Companion Manager**: Add travel buddies with personalized avatars and colors.
- **Shared Bills Logging**: Record meals, trains, and lodging with custom or equal participant splits.
- **Greedy Debt Minimization Algorithm**: Simplifies complex webs of group expenses into the absolute minimum number of payments.
- **1-Click WhatsApp Settlement Export**: Formats a clean, ready-to-send summary with totals, individual net balances, and who pays whom.

### 3. 🗣️ Native Audio Voice Translator & Dietary Allergy Flashcards
- **Interactive Multi-Language Speech Engine**: Web Speech API audio synthesis with speed pacing toggle (Normal 0.85x vs Slow 0.65x for learning).
- **Fullscreen Emergency & Dietary Cards**: High-contrast, large-typography cards in local script designed to show directly to waitstaff and taxi drivers:
  - 🥜 *Severe Peanut & Tree Nut Anaphylaxis Warning*

### 4. 🛡️ Traveler Safety Shield & Destination Scam Radar
- **One-Tap Emergency Dialing**: Instant `tel:` links to local Police, Ambulance, Fire Department, and universal GSM helpline numbers.
- **Active Tourist Scams Radar**: Curated intelligence database of real scams (e.g. *Kabukicho nightlife touting, Montmartre friendship bracelets, Colosseum gladiator photo ambush, Barcelona mustard distraction, tuk-tuk closures*) with threat levels and actionable field defenses.

### 5. 🌅 Golden Hour & Photo Spot Radar
- **Astronomical Solar Ephemeris**: Calculates Sunrise, Morning Golden Hour, Solar Noon, Evening Golden Hour, Sunset, and Blue Hour based on destination coordinates.
- **Curated Photography Vantage Points**: Top photo locations with recommended focal lengths (Wide-angle, Fast Prime, Telephoto), lighting angles, and drone / tripod regulations.

### 6. 📖 Offline Travel Pocket Booklet & Print / PDF Pass
- **Battery-Saving Offline Mode**: Formatted specifically for paper folding or offline reading when roaming data is unavailable.
- **Show-to-Driver Taxi Card**: Large destination name, coordinates, and local phrasing.
- **Condensed Master Timetable**: Daily morning, afternoon, and evening schedule with emergency hotlines and luggage checklists.

### 7. 🎯 Trip Planning & Customization
- **Global Autocomplete Search**: Interactive search across top global destinations with country badges and emoji markers.
- **Duration & Budget Tiers**: Choose 1 to 14 days with benchmarks for **Economy** ($), **Moderate** ($$), and **Luxury** ($$$).
- **Travel Companion & Vibes**: Solo, Couple, Family, Friends with vibes like *Foodie, Cultural, Adventure, Relaxed, Photography, Nightlife*.

### 8. 🗺️ Interactive Google Maps & Route Paths
- **Custom Categorized Markers**:
  - 🟣 Attractions & Sightseeing

### 9. 🧠 Geospatial AI Route Distance Optimizer (TSP)
- **Haversine Distance & TSP Heuristic**: Calculates geographic distances between scheduled stops for each day.
- **1-Click Route Optimization**: Eliminates backtracking, computes kilometers saved and estimated transit minutes saved.

### 10. 🚆 Nearby Excursions & Day Trip Extensions
- **Curated Day Trips**: Recommends nearby escapes (e.g. *Mount Fuji, Kamakura, Nikko from Tokyo*; *Versailles, Giverny, Champagne from Paris*).
- **1-Click Add**: Extends your trip duration and appends the day trip directly to the active itinerary.

### 11. ✈️ Smart Flight & Hotel Booking Finder
- **Pre-Configured Deep Links**: 1-click links to **Google Flights**, **Skyscanner**, **Booking.com**, and **Airbnb** with pre-filled destination parameters.

### 12. 🧾 Real-Time Travel Expense Tracker
- **Budget Consumed Progress Bar**: Compares actual spend against the estimated AI trip budget.
- **Receipt Logger**: Log expenses categorized by *Food, Transit, Lodging, Activities, Shopping*. Stored in `localStorage`.

### 13. 📅 Direct Calendar Sync & Multi-Currency Converter
- **`.ics` iCalendar Export**: Imports the itinerary with minute-accurate timing into **Google Calendar**, **Apple Calendar**, or **Outlook**.
- **Multi-Currency Converter**: Instant currency switcher between **USD ($)**, **EUR (€)**, **GBP (£)**, **JPY (¥)**, **INR (₹)**, **AUD (A$)**, and **CAD (C$)**.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router) + TypeScript 5 + React 19
- **Styling**: Tailwind CSS v4
- **AI Engine**: OpenAI API (`gpt-4o-mini`) + Intelligent Heuristic Fallback
- **Maps**: Google Maps JavaScript API + Vector GIS Canvas Fallback
- **Audio**: Web Speech API (`SpeechSynthesis`)
- **Algorithms**: Haversine Distance, 2-Opt TSP Nearest Neighbor, Greedy Debt Simplification
- **Calendar**: RFC 5545 iCalendar (`.ics`) standard
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage with JSON export/import and deep-link sharing

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment Variables (Optional)

```bash
cp .env.example .env.local
```

```env
OPENAI_API_KEY=sk-proj-...
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIzaSy...
```

*(Note: API keys can also be configured directly in the browser via the **"API Keys"** button in the header).*

### 3. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production

```bash
npm run build
npm start
```
